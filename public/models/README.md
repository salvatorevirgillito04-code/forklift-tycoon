# Modelli 3D

Metti qui i file `.glb`: il gioco li usa al posto dei modelli procedurali.

| File | Cosa | Orientamento atteso |
|---|---|---|
| `forklift.glb` | Corpo del muletto (senza montante e forche) | Fronte verso +Z, ruote a terra (y=0), metri |
| `mast.glb` | Montante + forche | Si muove su e giu da solo, origine alla base |
| `truck.glb` | Motrice + pianale | Lungo l'asse X, cabina verso +X |
| `pallet.glb` | Pallet con carico | Centrato, base a y=0, 1.2 x 1.2 m |
